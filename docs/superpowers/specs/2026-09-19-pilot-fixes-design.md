# Pilot-001–004 产品修复设计

用户已授权修复前轮四项问题。仅改善类别输入、复核权限、抄表检索与报表解释；不变更价格、用量、收付款或补差计算，不变更schema，不移动release标签。

1. 类别使用可输入的AutoComplete，建议来自同租户历史水表户和ACTIVE资费的去重用水类别，通过customer:read端点提供，输入新类别仍允许。保留Form label关联，加载失败有中文提示。与纯硬编码三类别相比，采用当前真实类别避免资费匹配名称失真；完整类别管理模块留待后续。
2. 新增独立metering:qc ACTION权限。QC路由允许metering:qc或原metering:write，维持已有管理员/抄表员行为；reviewer只新增qc，不获得录入、更正、导入、收费或IAM权限。增加幂等、指定租户的数据升级脚本，不通过重跑seed改密码/参数。新库seed也绑定qc。
3. GET抄表记录增加q过滤（户号、客户名、地址），在分页前使用同租户关系查询。列表/详情按需返回户号、客户、地址、表号和抄表/质检员工显示名，只返回显示字段、不暴露密码或员工完整档案。保留现有ID过滤兼容旧脚本。前端内滚动表格展示业务身份，检索按Enter提交，切换过滤重置页码。
4. 净应收负数时指标展示“—”和中文原因；原始应收/实收仍展示，API rate原值不改。常驻文字解释应收按账单账期、实收按收款日期，支持已有截止月累计查询。不将负比率渲染为正常经营指标。

验证先红后绿：Chrome真实UI、后端403/跨租户/范围探测、已有API抄表测试、完整77 UAT以及16 Pilot持续状态复核。修复测试使用Pilot备份克隆库，原长期库不被测试fixture污染；结束后部署本机修复build回原Pilot库，仅运行reviewer权限增量升级。报告保留原历史证据并追加Fix Cycle结果。
