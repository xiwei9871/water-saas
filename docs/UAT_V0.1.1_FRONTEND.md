# v0.1.1 前端 UAT 验收清单

版本基线：`v0.1.1-mvp`  
测试对象：React 管理端 + NestJS API + PostgreSQL fresh DB  
目标：验证真实业务操作链、角色权限、错误反馈、页面可用性与关键财务流程。  
结果分级：P0=阻塞试用；P1=高优先级缺陷；P2=体验/易用性；P3=建议。

## 自动化执行口径

Playwright 自动化覆盖：
- 登录与会话恢复
- 全路由 smoke + console/pageerror 捕获
- 立户向导
- 抄表计划开始→实抄录入→QC
- 结算终审
- 开账执行
- 柜台全额收款 + 收据打印
- 日结
- 报表页面 smoke
- 1280/1024 body 级横向溢出检查

未自动化项目保留为人工 UAT / v0.2 backlog 候选，不因自动化未覆盖而视为通过。
