## 三、业务闭环测试（核心链路，按顺序跑）

**链路 A：立户→抄表→结算→开账→收费→日结→报表**

| # | 操作 | 预期 |
|---|---|---|
| A1 | 立户向导新建客户+用水户+表（记户号） | 各列表可查，户号 A 开头规则编号 |
| A2 | 抄表册挂该户表→抄表计划生成当期 | 计划项出现 |
| A3 | 抄表记录录入读数 | 状态「待质检」 |
| A4 | 录入一条**低于上期**的读数再 QC | 质检通过时弹出补差确认框（候选责任人名单可见） |
| A5 | 结算水量→生成结算单 | 出结算记录；若该户有未完成任务 → 阻断提示含任务名+候选人 |
| A6 | 开账批次生成账单 | 账单状态「已出账」，费用构成显示 `¥X.XX/m³ × N m³` |
| A7 | 收费台对结算户收款 | 生成收款单+收据号，账单变「已缴清/部分缴费」 |
| A8 | 收费员日结提交 | 日结记录生成，金额与当日收款一致 |
| A9 | 月报核对 | 应收/实收/回收率与 A6-A7 数据能对上 |
| A10 | 统一查询勾选「应收金额+实收金额」跨该账期 | 该行数值与账单/收款一致 |
